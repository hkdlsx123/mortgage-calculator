# 🏠 房贷计算器 (Mortgage Calculator)

纯前端、零依赖、单文件的中国房贷计算器。支持组合贷（商贷 + 公积金）、等额本息/等额本金、多次提前还款、LPR 利率调整模拟、月度还款明细。

**打开即用：** 下载 `index.html` 用浏览器打开，或部署到任意静态服务器。数据完全在本地计算，不经过任何服务器。

## ✨ 功能

- **组合贷**：商贷 + 公积金独立参数，各自可选等额本息/等额本金，不参与的贷款金额填 0 即可
- **等额本息 / 等额本金**：标准年金公式逐月摊销，利息按分计（银行账单口径），尾差并入最后一期结清
- **提前还款**：支持多次，每笔可选
  - **缩期**（月供不变，缩短剩余期数）
  - **减月供**（期限不变，重新计算月供）
- **利率调整**：支持多次，模拟 LPR 重定价——从第 N 期起按剩余本金 + 剩余期数 + 新年利率重算月供
- **月度明细表**：逐月本金 / 利息 / 余额，提前还款行、利率调整行高亮标记，支持总览 / 商贷 / 公积金 tab 切换
- **方案对比**：保存多套参数并排比较清贷时间、总利息、较基准省息
- **参数自动保存**：输入自动存入 localStorage，下次打开自动恢复
- **移动端适配**：手机浏览自动切换单列布局

## 🚀 使用方法

1. 下载 `index.html`
2. 双击用浏览器打开（或部署到任意静态服务器 / GitHub Pages）
3. 填写贷款参数 → 点击「开始计算」

在线演示（GitHub Pages）：见仓库 Settings → Pages 开启后生成的地址。

## 🧮 计算口径

- 等额本息：`pmt = P × r × (1+r)ⁿ / ((1+r)ⁿ − 1)`，每月利息 = 剩余本金 × 月利率，尾期微调
- 等额本金：月还本金 = 贷款本金 / 期数（固定），利息逐月递减
- 金额内部以「元」计算，展示保留 2 位；利息、本金每期舍入到分
- 提前还款「缩期」：月供（或月还本金）不变，按剩余本金反推剩余期数
- 提前还款「减月供」：剩余期数不变，按剩余本金重算月供
- 利率调整：等额本息按剩余本金 + 剩余期数重算月供；等额本金仅改利率、月还本金不变

> 结果仅供参考，以银行实际账单为准。
